# Bundled interface fonts

These unmodified variable fonts come from the official [Google Fonts repository](https://github.com/google/fonts). They preserve the App's existing interface typography and are included locally so builds do not depend on the Google Fonts CSS service.

- Plus Jakarta Sans: [source](https://github.com/google/fonts/blob/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf), Git blob `0cb13a998ed525ba226d911b10d6c4c4f923a961`. Copyright and license: [PlusJakartaSans-OFL.txt](./PlusJakartaSans-OFL.txt).
- JetBrains Mono: [source](https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/JetBrainsMono%5Bwght%5D.ttf), Git blob `aa310be8b717fe3774f9444dd89d5f4101cc6d10`. Copyright and license: [JetBrainsMono-OFL.txt](./JetBrainsMono-OFL.txt).

Both fonts use the SIL Open Font License 1.1. Their files and notices are distributed in the App's public assets.
